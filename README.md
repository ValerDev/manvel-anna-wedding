# Manvel & Anna — Wedding Invitation

Responsive, animated wedding invitation based on `V1.pdf`. Built with plain HTML, CSS, and JavaScript and ready for GitHub Pages.

## Preview

Open `index.html` directly, or run a local server:

```powershell
npx serve .
```

## Customize maps

Replace the three values in `MAP_URLS` at the top of `js/script.js` with the final Google Maps share links.

## Publish with GitHub Pages

Push the `main` branch, then configure Pages to deploy from `main` and `/ (root)` in the repository settings.
